GitHub 云同步（免部署 · 出差换机首选）

· 不需要服务器、不用买域名：页面放 GitHub Pages，数据存在你自己的私有 Gist 里。
· Token 只保存在当前浏览器，不上传任何第三方；Gist 为私有，只有 Token 能读写。
· 连接后每次改动自动上传；手机 / 公司电脑打开同一网址、粘贴同一个 Token，会自动拉取最新数据。
· 换设备时如果服务器上已有数据，会按「较新时间」自动决定拉取还是上传。

自建服务器同步（需要自己部署服务器）

· 把本页部署到你自己的服务器（私域网站），用 https:// 打开 → 输入访问密码登录，数据就存在服务器上。
· 登录后每次改动会自动上传；换电脑只需打开同一个网址、登录，数据自动跟着走，不用网盘拷贝。
· 没部署 / 断网时自动退回本地模式，数据仍存在本机浏览器，不报错、不丢。
· 两台机器以「较新时间」为准，会覆盖不合并；出差期间尽量只用一台编辑。

数据备份 / 文件导入导出

把 JSON / Excel 文件拖到这里导入（从微信、资源管理器直接拖入即可）

· 文件导入会自动识别「甲方端 / 乘客端 / 成单」等表，以及每张表里左右并排的「出国 / 回国」两块；时间列的 Excel 日期数字（如 46305）会自动转成「10月10日」。
· 若在 Trae 预览窗口里点「导入台账」跳到空白页，请改用上面的粘贴导入、或把 Excel 文件直接拖到本页，也可以下载 html 后用 Chrome/Edge 打开再导入。
· 导入是追加，重复导入同一条会出现多次；建议导入前先「清空全部数据」或导出备份。
